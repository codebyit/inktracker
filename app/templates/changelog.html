v0.16.0 - Materials Library, Printer Profiles & Project Fixes

Released 2026-08-07

New Features

  • Materials library and BOM integration - Autocomplete materials in project bills of materials, prefill cost and unit details, optionally save new materials, and track linked-material consumption.
  • Printer-profile quality options - Quality choices now match the selected printer profile; eufyMake no longer offers the unsupported Ultra option.
  • Added a Printer Profile selector under Settings > Machine.

Fixes

  • Edit Project now preserves a 0.00 mm white underbase choke and the Include Pre-Prime Ink setting.
  • Improved dark-mode contrast for White Ink Type labels in the New Project wizard.

Security

  • Hardened embedded wizard data and documentation links.
  • Interactive API documentation is disabled by default.

v0.15.0 - Clearer Ink Corrections & Maintenance Workflow

Released 2026-07-14

Improvements

  • Set current ink levels directly instead of calculating +/- corrections manually.
  • Service Action Log entries now support per-channel breakdowns and undo.
  • Cleaning and moisturizing liquid are shown as one UV Cleaning Cartridge.
  • Improved ink-level bounds, correction feedback, and maintenance-log reliability.

v0.9.0 – Multi-Craft Support

Released 2026-06-28

New Features

  • Multiple craft modes per project – Define different finishes for each face (e.g., 2-sided case: Side A = Flat Raised, Side B = Flat)
  • Craft variant breakdown in project detail view
  • Enhanced wizard UX for multi-face projects

Technical Updates

  • Tailwind CSS v4 for faster builds and improved styling
  • Multi-craft data persistence in SQLAlchemy models

Security

  • Hardened the project print worksheet against cross-site scripting (XSS) by escaping all user- and config-derived values
  • Removed a file-access race condition in the release tooling

Compatibility

  • All existing single-craft projects work unchanged
  • Multi-craft is opt-in via project toggle in the wizard

v0.6.8 – Project Metadata Persistence

Released 2026-06-15

Improvements

  • Project metadata (material, craft mode) now persisted across edits
  • Craft ink mode synced into active ink-mode calculations
  • SQLite migration compatibility fixes

v0.6.7 – Security & Craft Mode Enhancements

Released 2026-06-01

Improvements

  • Expanded craft mode controls (Flat Raised, Pattern Texture, Relief Texture, Customize)
  • GitHub Actions security pipeline (Bandit + pip-audit)
  • Startup reliability diagnostics and migration timeout guards
